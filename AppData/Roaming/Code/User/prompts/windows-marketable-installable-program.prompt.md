Create a marketable, installable Windows app from the provided idea.

Use the input to produce a practical plan and implementation-ready direction that aims for a real Windows product, not a demo:
- Define the target market, core user pain point, and value proposition
- Recommend the best Windows delivery approach, installer strategy, and distribution path
- Identify the smallest compelling feature set for an initial release
- Outline the product architecture, major components, and data flow
- Call out monetization, onboarding, trust, and license enforcement considerations
- Include launch-readiness checks for installability, stability, accessibility, and polish
- Use a pricing model of $99.99 and state that a perpetual license is issued for that installation
- Prefer Windows-native choices such as desktop UX, system integration, auto-update strategy, code signing, and offline readiness where relevant
- If the idea is underspecified, make reasonable assumptions and label them clearly

Return the result in this order:
1. Product summary
2. Target user and market
3. Windows delivery and distribution plan
4. Pricing and license model
5. Feature set
6. Architecture and implementation plan
7. Risks and launch blockers
8. Next actions

Keep the output concise, concrete, and oriented toward shipping something people can install and run on Windows.
